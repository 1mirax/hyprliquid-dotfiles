# Every package this configuration needs, verified against a working install.
#
# pacman reads names from stdin but does NOT understand comments, so feeding
# this file to it directly makes every comment a package name and the whole
# command fails. Strip them first:
#
#   sed 's/#.*//' packages.txt | awk 'NF{print $1}' | sudo pacman -S --needed -
#
# awk rather than grep: cutting the comment leaves the whitespace that lined it
# up, and pacman then looks for a package called "swaybg                    ".
# `NF{print $1}` takes the first field and drops blank lines in one step.
#
# Everything above the AUR section is in the official repositories. The two
# AUR packages at the bottom are the Bluetooth and audio menus; the setup
# works without them, see the note there.

# --- compositor and session ---------------------------------------------
hyprland
hyprlock
hypridle
swaybg                      # wallpaper; no IPC, the process is the wallpaper
hyprcursor
uwsm                        # session manager: runs the daemons as systemd units
# Only the Hyprland backend, on purpose. It implements the compositor-specific
# interfaces - screen capture, global shortcuts - and nothing else. The usual
# companion, xdg-desktop-portal-gtk, would add AppChooser, Print, Notification
# and friends, all of which exist for sandboxed apps that are not installed
# here, plus Settings.
#
# Settings is the one real loss: it is how an application asks the session
# whether to prefer a dark theme over D-Bus. GTK apps do not need it, they read
# gtk-application-prefer-dark-theme from .config/gtk-3.0/settings.ini directly.
# Firefox does use it, so with no backend for it the browser must be told to
# use a dark theme in its own settings. That is the trade: one manual setting
# against a 6.5 MB resident process.
xdg-desktop-portal-hyprland

# --- sound --------------------------------------------------------------
# All four are required. pipewire alone is only the engine: without
# wireplumber nothing claims the hardware and the graph holds two dummy nodes,
# and without pipewire-pulse there is no socket for Firefox and everything
# else that speaks only the PulseAudio protocol.
pipewire
wireplumber                 # session manager - decides what connects to what
pipewire-pulse              # PulseAudio protocol, for Firefox, Electron, Wine
pipewire-alsa               # routes ALSA-only applications into the graph
alsa-utils                  # aplay / amixer, for diagnosing the bottom layer

# --- bluetooth ----------------------------------------------------------
bluez
bluez-utils                 # bluetoothctl

# --- hardware controls --------------------------------------------------
brightnessctl
polkit-gnome                # the authentication agent

# --- shell -------------------------------------------------------------
fish
starship

# --- editing -------------------------------------------------------------
# nvim alone. nano was here for one run on the reasoning that it is the editor
# you meet everywhere - and that turned out to be wrong on the machine it was
# written for: Arch's `base` carries neither nano nor vi, so a fresh install
# has no editor at all until one is named here. What IS close to universal on
# someone else's machine is `vi`, which POSIX requires and which nano is not.
#
# So the fallback argument evaporated, and learning vim motions covers the
# rescue case better than carrying a second editor. The Arch ISO still ships
# nano if a broken system ever has to be fixed from outside.
neovim
ripgrep                     # :Tutor needs neither, a plugin config will
fd                          # and both are worth having on their own
unzip

# --- power management (see .config/power/install.sh) --------------------
tlp
throttled                   # ThinkPad only - power/install.sh detects the machine
                            # and skips it entirely anywhere else

# --- what the scripts shell out to --------------------------------------
# Easy to miss because nothing links against them: they are called by name,
# so a missing one fails at runtime rather than at install time.
jq                          # every script that reads `hyprctl -j`
libnotify                   # notify-send - the OSD, Wi-Fi and wallpaper toasts
networkmanager              # nmcli, behind the bar's network module
ffmpeg                      # optional: pre-scales a wallpaper to the panel
                            # size once, so swaybg decodes a small file on
                            # every start. Without it the original is used.

# --- libraries the scripts and bar link against -------------------------
python-gobject              # fix-oversized-icons.py uses GdkPixbuf
gtk-layer-shell             # waybar needs it

noto-fonts

qt5-wayland
qt6-wayland

# --- login ---------------------------------------------------------------
# A display manager is not strictly required - `uwsm start hyprland-uwsm.desktop`
# from a TTY brings the same session up - but it is what runs here:
#   sudo systemctl enable ly@tty2.service
# and then pick "Hyprland (uwsm)" at the prompt, not plain "Hyprland", or the
# daemons fall back to the Lua autostart path.
ly                          # TUI display manager, one tty, no X

# --- optional -----------------------------------------------------------
btop                        # what the CPU and RAM modules open on click

# --- AUR ----------------------------------------------------------------
# Both are single binaries that drive fuzzel; neither is required for the
# session to come up. Without bzmenu the Bluetooth key falls back to
# scripts/bluetooth.sh, which needs only bluez-utils. Without pwmenu there is
# no device picker, but the volume keys keep working through wpctl.
#
#   yay -S --needed bzmenu-bin pwmenu-bin networkmanager-dmenu-git
#
# bzmenu-bin                Bluetooth menu, talks to BlueZ over D-Bus
# pwmenu-bin                audio menu, talks to PipeWire natively
# networkmanager-dmenu-git  Wi-Fi menu; reaches saved connections, VPN and
#                           WireGuard, hotspots and the password QR code.
#                           Without it Super+ALT+I still picks a network
#                           through scripts/network.sh and plain nmcli.
